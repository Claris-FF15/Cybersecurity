## task 2 System Configuration and Advanced System Settings

What is the name of the service that lists Systems Internals as the manufacturer?

* look in the service in mfconfig 
* the answer is psShutdown

Whom is the Windows license registered to?

* Windows user

What is the command for Windows Troubleshooting?

* look in the tools about Troubleshooting and click on it.
* the answer is C:\Windows\System32\control.exe /name Microsoft.Troubleshooting

What command will open the Control Panel? (The answer is  the name of .exe, not the full path)

* control.exe


## task 3 Change UAC Settings

What is the command to open User Account Control Settings? (The answer is the name of the .exe file, not the full path)

* look in msconfig tools search about Change UAC Settings and click on it
* the answer is UserAccountControlSettings.exe
